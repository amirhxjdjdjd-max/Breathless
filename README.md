# پناه | چند دقیقه برای خودت

وب‌سایت فارسی، راست‌چین و واکنش‌گرا برای تمرین تنفس، توجه به حال‌و‌هوا، نوشتن و رها کردن احساسات و ساختن یک باغ کوچک.

## اجرا

فایل `index.html` را مستقیماً در مرورگر باز کنید. هیچ کتابخانه، سرور یا فایل خارجی لازم نیست.

## انتشار روی GitHub Pages

1. فایل‌های `index.html` و `README.md` را در ریشه مخزن GitHub قرار دهید.
2. وارد **Settings → Pages** شوید.
3. گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.

## امکانات

- چهار تمرین تنفس با توضیح کاربرد، گوی متحرک و صدای ملایم تولیدشده در مرورگر
- نمایش ۷۵ جمله آرامش‌بخش متناسب با حال انتخاب‌شده
- نوشتن و رها کردن متن با افکت محو شدن
- باغی که با هر کلیک یک گل به آن اضافه می‌شود
- حالت شب به‌صورت پیش‌فرض و امکان تغییر به حالت روز؛ انتخاب کاربر در مرورگر ذخیره می‌شود
- طراحی واکنش‌گرا و پشتیبانی از تنظیم کاهش حرکت

## حریم خصوصی

متن بخش «رها کردن» فقط در حافظه همان صفحه پردازش می‌شود؛ به سرور ارسال یا در فضای ذخیره‌سازی مرورگر ثبت نمی‌شود. صدا با Web Audio API و در خود مرورگر ساخته می‌شود.
