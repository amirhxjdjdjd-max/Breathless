# پناه | چند دقیقه برای خودت

وب‌سایت فارسی، راست‌چین و واکنش‌گرا برای تمرین تنفس، توجه به حال‌وهوا، نوشتن و رها کردن احساسات و ساختن یک باغ کوچک.

## اجرا

فایل `index.html` را مستقیماً در مرورگر باز کنید. هیچ کتابخانه، سرور یا فایل خارجی لازم نیست.

## انتشار روی GitHub Pages

1. فایل‌های `index.html` و `README.md` را در ریشه مخزن GitHub قرار دهید.
2. وارد **Settings → Pages** شوید.
3. گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.

## امکانات

- چهار تمرین تنفس با توضیح کاربرد، گوی متحرک و صدای ملایم تولیدشده در مرورگر
- ۶۰۰۰ پیام آرامش‌بخش متفاوت؛ ۱۲۰۰ پیام برای هر یک از ۵ حال‌وهوا
- ترتیب پیام‌های دیده‌شده برای هر حال‌وهوا ذخیره می‌شود و تا پایان دور، پیام تکراری نمایش داده نمی‌شود
- نوشتن و رها کردن متن با افکت محو شدن
- باغ گل ذخیره‌شونده با امکان پاک کردن همه گل‌ها فقط با انتخاب و تأیید خود کاربر
- ذخیره حال‌وهوای انتخابی، نوع تمرین تنفس و وضعیت صدای آرام
- حالت شب به‌صورت پیش‌فرض و امکان تغییر به حالت روز؛ انتخاب کاربر در مرورگر ذخیره می‌شود
- طراحی واکنش‌گرا و پشتیبانی از تنظیم کاهش حرکت

## ذخیره‌سازی و حریم خصوصی

انتخاب‌ها، باغ و پیشرفت پیام‌ها با `localStorage` در همان مرورگر و دستگاه ذخیره می‌شوند؛ بنابراین با بستن و بازکردن دوباره سایت باقی می‌مانند. چون این نسخه حساب کاربری یا سرور ندارد، اطلاعات بین دستگاه‌های مختلف همگام نمی‌شوند و افراد مختلفی که از یک پروفایل مرورگر مشترک استفاده می‌کنند، داده‌های همان پروفایل را می‌بینند.

متن بخش «رها کردن» فقط در حافظه همان صفحه پردازش می‌شود؛ به سرور ارسال یا در فضای ذخیره‌سازی مرورگر ثبت نمی‌شود. صدا با Web Audio API و در خود مرورگر ساخته می‌شود.
