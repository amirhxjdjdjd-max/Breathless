# پناه | سایت آرامش و تنفس

یک وب‌سایت فارسی، راست‌چین و واکنش‌گرا برای تمرین تنفس، توجه به حال‌و‌هوا، نوشتن و رها کردن احساسات و ساختن یک باغ کوچک.

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید. هیچ کتابخانه، سرور یا فایل خارجی لازم نیست.

## انتشار روی GitHub Pages

1. یک مخزن جدید در GitHub بسازید.
2. فایل `index.html` و `README.md` را در ریشه مخزن بارگذاری کنید.
3. در مخزن به مسیر **Settings → Pages** بروید.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
6. پس از انتشار، نشانی GitHub Pages مخزن نمایش داده می‌شود.

## امکانات

- چهار الگوی تنفس با گوی متحرک و صدای ملایم تولیدشده در مرورگر
- جمله‌های آرام‌کننده متناسب با حال انتخاب‌شده
- نوشتن و رها کردن متن با افکت محو شدن و صدای کوتاه
- باغی که از صفر شروع می‌شود و با هر کلیک یک گل به آن اضافه می‌شود
- حالت شب با دکمه تغییر پوسته و ذخیره خودکار انتخاب کاربر در مرورگر
- طراحی واکنش‌گرا، پشتیبانی از صفحه‌کلید و تنظیم کاهش حرکت

## حریم خصوصی

متن بخش «رها کردن» فقط در حافظه همان صفحه پردازش می‌شود؛ به سرور ارسال یا در فضای ذخیره‌سازی مرورگر ثبت نمی‌شود. صدا با Web Audio API و در خود مرورگر ساخته می‌شود.
