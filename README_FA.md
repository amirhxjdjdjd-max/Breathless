# پناه 🌿

یک وب‌سایت فارسی و راست‌چین برای مکث، نفس‌کشیدن و آرام‌تر شدن. این نسخه بدون بک‌اند و بدون نیاز به نصب پکیج، مستقیماً روی GitHub Pages اجرا می‌شود.

## فایل‌های پروژه

- `index.html` — ساختار و متن‌های سایت
- `style.css` — ظاهر واکنش‌گرا و انیمیشن‌ها
- `script.js` — کدهای تعاملی بازنویسی‌شده
- `assets/audio/rain.wav` — صدای باران
- `assets/audio/ocean.wav` — صدای موج دریا
- `assets/audio/wind.wav` — صدای نسیم
- `assets/audio/release-chime.wav` — صدای کوتاه هنگام رهاکردن نوشته
- `assets/favicon.svg` — آیکون سایت

## انتشار درست روی GitHub Pages

1. فایل ZIP را باز کن.
2. **محتویات داخل پوشه را مستقیم** در ریشه Repository قرار بده؛ یعنی `index.html` باید کنار `style.css` و `script.js` باشد، نه داخل یک پوشه‌ی اضافی به نام `panah`.
3. پوشه‌ی `assets` را هم کامل بارگذاری کن؛ مخصوصاً فایل‌های صوتی داخل `assets/audio` را.
4. در GitHub وارد `Settings → Pages` شو و منبع انتشار را روی شاخه‌ی `main` و پوشه‌ی `/ (root)` قرار بده.
5. بعد از انتشار، سایت را دوباره باز کن. فایل‌های CSS و JavaScript نسخه‌بندی شده‌اند تا نسخه‌ی قدیمی کش‌شده کمتر مزاحم شود.

## رفتار قابلیت‌ها

- باغ در هر بار بارگذاری کامل صفحه از صفر و بدون گل شروع می‌شود. هر بار فشردن «یک گل بکار» فقط یک گل تازه اضافه می‌کند. تعداد گل‌ها در حافظه‌ی مرورگر ذخیره نمی‌شود.
- سه صدای آرامش، فایل‌های صوتی محلی هستند و با فشردن دکمه‌ی پخش شروع می‌شوند؛ اینترنت برای پخش آن‌ها لازم نیست.
- دکمه‌ی «برگردیم به شروع» و دکمه‌ی شناور پایین صفحه، مستقیم به بالای صفحه می‌روند.
- در بخش «سبک‌تر شو»، نوشته پس از فشردن «رهایش کن» با انیمیشن محو و صدای کوتاه محلی ناپدید می‌شود. متن نوشته‌شده به سرور فرستاده یا در مرورگر ذخیره نمی‌شود.
- تمرین تنفس راهنمای عمومی آرام‌سازی است؛ ریتم طبیعی بدن خودت را در اولویت بگذار و نفس را به زور نگه ندار.
