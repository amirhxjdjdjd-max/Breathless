# یه نفس 🌿

یک وب‌سایت فارسی، راست‌چین و واکنش‌گرا برای مکث، تنفس و آرامش روزمره. این پروژه برای انتشار مستقیم روی **GitHub Pages** آماده شده است و به بک‌اند، نصب پکیج یا فرایند build نیاز ندارد.

## فایل‌ها

- `index.html` — ساختار و محتوای سایت
- `style.css` — طراحی واکنش‌گرا، رنگ‌ها، انیمیشن‌ها و حالت کم‌حرکتی
- `script.js` — تمرین تنفس، صداهای تولیدشده در مرورگر، انتخاب حال، باغ تعاملی و یادداشت خصوصی
- `assets/favicon.svg` — آیکون سایت

## انتشار روی GitHub Pages

1. یک Repository جدید در GitHub بساز.
2. تمام فایل‌ها و پوشه‌های همین پروژه را در ریشه Repository بارگذاری کن؛ یعنی `index.html` باید در ریشه باشد.
3. وارد **Settings → Pages** شو.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کن.
6. پس از انتشار، آدرس سایت در همان صفحه نمایش داده می‌شود.

## نکات حریم خصوصی و فنی

- سایت هیچ فرم ثبت‌نام، تبلیغ، ردیاب یا درخواست به سرور خارجی ندارد.
- متن بخش «سبک‌تر شو» فقط در همان صفحه استفاده می‌شود؛ ذخیره یا ارسال نمی‌شود.
- تعداد گل‌های باغ، در صورت فعال بودن Local Storage مرورگر، فقط روی همان دستگاه ذخیره می‌شود.
- صداها به‌صورت ساده و مصنوعی با Web Audio API ساخته می‌شوند و فقط پس از لمس دکمه پخش فعال می‌شوند. این صداها فایل ضبط‌شده طبیعت نیستند.
- مرورگر ممکن است در اولین بار اجازه پخش صدا را فقط پس از تعامل کاربر بدهد.
- تمرین تنفس یک تجربه عمومی آرام‌سازی است و جایگزین مشاوره یا مراقبت تخصصی نیست. کاربر باید با ریتم طبیعی و راحت بدن خود پیش برود.

## شخصی‌سازی

متن‌ها در `index.html` و `script.js`، رنگ‌ها در ابتدای `style.css` و نام توسعه‌دهنده در بخش انتهایی `index.html` قرار دارند.
