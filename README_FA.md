# یه نفس 🌿 — نسخه‌ی تقویت‌شده

یک وب‌سایت فارسی، راست‌چین و واکنش‌گرا برای مکث، تنفس و آرامش روزمره. این پروژه برای انتشار مستقیم روی **GitHub Pages** آماده است و به بک‌اند، نصب پکیج یا فرایند build نیاز ندارد.

## فایل‌ها

- `index.html` — ساختار و محتوای سایت، منظره‌های تصویری و متن‌های فارسی
- `style.css` — طراحی واکنش‌گرا، عکس‌های پس‌زمینه، افکت‌ها و حالت کم‌حرکتی
- `script.js` — تمرین تنفس دقیق، صداهای اختیاری، انتخاب حال، باغ ذخیره‌شونده و انیمیشن رها کردن نوشته
- `assets/favicon.svg` — آیکون سایت

## انتشار روی GitHub Pages

1. یک Repository جدید در GitHub بساز.
2. تمام فایل‌ها و پوشه‌های همین پروژه را در ریشه Repository بارگذاری کن؛ یعنی `index.html` باید در ریشه باشد.
3. وارد **Settings → Pages** شو.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کن.
6. آدرس سایت پس از انتشار در همان صفحه نمایش داده می‌شود.

## قابلیت‌ها و اصلاحات این نسخه

- تمرین تنفس با شمارش زمان هماهنگ، سه زمان انتخابی و صدای راهنمای بسیار ملایم برای دم، مکث و بازدم؛ صدای راهنما جداگانه روشن/خاموش می‌شود.
- صداهای پس‌زمینه‌ی باران، موج و نسیم با کنترل بلندی صدا؛ پخش فقط پس از لمس کاربر آغاز می‌شود.
- سه منظره‌ی عکاسی‌شده؛ با انتخاب هر منظره صدای مرتبط با آن پخش می‌شود.
- باغ تصویری با گل‌های قابل کاشت؛ تعداد و چیدمان گل‌ها روی همان دستگاه به یاد می‌ماند.
- پیام‌های خودمانی و متنوع برای حال‌های مختلف و جمله‌های مهربانانه‌ی بیشتر.
- بخش نوشتن خصوصی با انیمیشن شناور شدن، محو شدن و ذره‌های نورانی، به همراه صدای ظریف رهاسازی؛ متن تنها پس از پایان انیمیشن از کادر پاک می‌شود.
- منوی موبایل با بستن خودکار، دکمه‌ی بازگشت به بالا، پشتیبانی بهتر از صفحه‌کلید و تنظیم کاهش حرکت.

## حریم خصوصی و نکات فنی

- سایت فرم ثبت‌نام، حساب کاربری یا سرور اختصاصی ندارد.
- نوشته‌ی بخش «سبک‌تر شو» به سرور فرستاده یا ذخیره نمی‌شود؛ فقط برای ساخت افکت در همان صفحه موقتاً در حافظه‌ی مرورگر قرار می‌گیرد و پس از پایان انیمیشن پاک می‌شود.
- تعداد گل‌های باغ فقط در Local Storage همان مرورگر ذخیره می‌شود.
- صداها با Web Audio API در مرورگر ساخته می‌شوند و فایل ضبط‌شده‌ی واقعی طبیعت یا صدای انسان نیستند. هیچ صدایی بدون انتخاب کاربر شروع نمی‌شود.
- اگر صدا برای کاربر خوشایند نبود، می‌تواند صدای راهنمای تنفس یا صدای محیط را جداگانه خاموش کند.
- تمرین تنفس یک تجربه‌ی عمومی آرام‌سازی است، نه درمان یا جایگزین مراقبت تخصصی. کاربر باید با ریتم راحت بدن خودش پیش برود و هر زمان احساس ناراحتی کرد تمرین را متوقف کند.
