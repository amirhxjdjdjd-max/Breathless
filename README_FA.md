# پناه 🌿

یک وب‌سایت فارسی، راست‌چین و واکنش‌گرا برای مکث، تنفس و آرامش روزمره. این پروژه برای انتشار مستقیم روی **GitHub Pages** آماده است و به بک‌اند، نصب پکیج یا فرایند build نیاز ندارد.

## فایل‌ها

- `index.html` — ساختار و متن‌های سایت
- `style.css` — طراحی واکنش‌گرا، انیمیشن‌ها و حالت کم‌حرکتی
- `script.js` — تمرین تنفس با مکث/ادامه، صدای راهنمای ملایم، صداهای طبیعت، باغ تعاملی و نوشته خصوصی
- `assets/favicon.svg` — آیکون پناه
- `assets/music/README_FA.md` — اطلاعات آرشیو ۱۶۶ آهنگی Open Lo-Fi و مجوز آن

## موسیقی

در بخش صداهای سایت، لینک مستقیم دانلود آرشیو رسمی Open Lo-Fi قرار دارد. این آرشیو ۱۶۶ قطعه در ۱۰ دسته دارد، حدود ۵۴۴ مگابایت حجم دارد و با مجوز CC0 1.0 منتشر شده است. برای سبک ماندن بستهٔ سایت، فایل بزرگ موسیقی داخل ZIP سایت کپی نشده و از لینک مستقیم رسمی دریافت می‌شود.

## انتشار روی GitHub Pages

1. یک Repository جدید در GitHub بساز.
2. همه فایل‌ها و پوشه‌های پروژه را در ریشه Repository بارگذاری کن؛ یعنی `index.html` باید در ریشه باشد.
3. وارد **Settings → Pages** شو.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کن.

## نکات فنی و حریم خصوصی

- سایت فرم ثبت‌نام یا ردیاب ندارد.
- متن بخش «سبک‌تر شو» فقط در همان صفحه استفاده می‌شود و به سرور فرستاده نمی‌شود.
- تعداد گل‌های باغ در صورت فعال بودن Local Storage فقط روی همان دستگاه ذخیره می‌شود.
- صدای باران، موج و نسیم با Web Audio API در مرورگر ساخته می‌شود؛ صدای راهنمای تمرین تنفس هم یک زنگ نرم و کم‌حجم است. هیچ صدایی بدون اقدام کاربر پخش نمی‌شود.
- تمرین تنفس اختیاری است؛ اگر مکث یا نفس عمیق راحت نبود، کاربر می‌تواند از آن رد شود یا تمرین را متوقف کند.
